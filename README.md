# tv-feed

Feed per app personali su una TV LG webOS: guide TV (Rai, Mediaset, Sky, WBD Aurora), cataloghi e lista canali,
scaricati e normalizzati ogni 30 minuti. Python stdlib, nessuna dipendenza.

- `python3 feed.py [out]` — un giro; `python3 feed.py serve [port]` — file statici con CORS.
- Uscita pubblicata su GitHub Pages (branch `gh-pages`) dal workflow `.github/workflows/feed.yml`.
- Formato e dettagli nella docstring di `feed.py`.
